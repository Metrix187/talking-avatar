Showcase page for [Metrix187/talking-avatar](https://github.com/Metrix187/talking-avatar):
a local, real-time talking portrait built on SoulX-FlashHead Lite, Kokoro and
faster-whisper.

This Space is a static page with a recorded clip. The app itself needs a GPU
with about 6 GB of VRAM and runs on your own machine; the code and setup steps
are in the GitHub repository. No model weights are hosted here.
